# How each faction's code looks when you watch it run (with a code scanner).
# A style applies to the governments it names and their variants ("Hai" also
# covers "Hai Merchant" and "Hai (Unfettered)"). It can set the colors of
# each part of the code ("keyword", "name", "number", "comment", "string",
# "paren", "background", and "lit" for lines that ran in the HUD's map), add
# comment lines at the top ("header"), and with a "cipher" (the letters to
# show for "a" through "z"), make the code unreadable while its numbers still
# show.
